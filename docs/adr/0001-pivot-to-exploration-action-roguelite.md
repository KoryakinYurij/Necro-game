# Pivot from arena survival to exploration/action roguelite

Necro will move away from a run structure dominated by automatic global pressure and toward procedural expeditions where the player chooses direction, encounters, POIs, and risks. This is a product-level identity decision: the map must create meaningful choices rather than merely separate fights with empty travel.

## Considered Options

- Keep the current Vampire Survivors-style arena loop and expand content.
- Keep the combat feel but make space and voluntary engagement the primary run structure.

We chose the second option because it better supports the necromancer fantasy and creates a more distinctive route/risk/reward identity.
